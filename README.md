# Relysh Dev website

Static, GitHub Pages-ready website for **Relysh Dev**, a mobile game development studio.

## Pages
- `index.html` — studio homepage
- `privacy.html` — general privacy policy
- `support.html` — support and contact page

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload the contents of this folder to the repository root.
3. In **Settings → Pages**, select **Deploy from a branch**, then choose `main` and `/ (root)`.
4. Configure your custom domain if desired.

## Important before launch
The contact addresses use the `relysh.dev` domain (`hello@`, `support@`, `privacy@`). Make sure these mailboxes/aliases exist, or replace them in the HTML.

The included privacy policy is a general starting point. Before publishing each Google Play app, update the policy and the Play Console Data safety disclosures so they accurately match the app's actual SDKs, data collection, advertising, account/deletion flows, audience, and retention practices.
